# 快速开始

从零到跑通第一次测速，大约 5 分钟。

---

## 1. 下载哪个版本

打开 [**Releases**](https://gitee.com/liliaic/cfstx/releases)，选最新版本：

| 文件 | 适合谁 | 特点 |
|---|---|---|
| `CFSTX-Setup-x.x.x.exe` | 长期使用（**推荐**） | 安装到用户目录、自动建快捷方式、支持应用内更新、可卸载 |
| `CFSTX-x.x.x-portable.zip` | 临时用 / 放 U 盘 | 解压即用，不写注册表，但**没有应用内更新** |

> [!NOTE]
> 程序未购买代码签名证书。首次运行时 Windows 可能提示「**Windows 已保护你的电脑**」或「无法验证发布者」——点击「**更多信息**」→「**仍要运行**」即可。
>
> 这是所有未签名程序的统一提示，不是病毒警告。

**系统要求**：Windows 10 / 11（x64）。

安装版依赖 **WebView2 运行时**：Windows 11 自带；Windows 10 若缺少，程序启动时会提示，按提示安装即可（微软官方免费组件）。

---

## 2. 安装

双击安装包，一路下一步。默认装到：

```text
%LOCALAPPDATA%\Programs\CFSTX\
```

这是**用户目录**，不需要管理员权限。

> Hosts 功能需要管理员权限，届时会单独提示。

---

## 3. 第一次打开

双击桌面快捷方式，或直接运行 `cfstx.exe`（**不带任何参数**）。

左侧有三个页面：

| 页面 | 用途 | 你什么时候需要 |
|---|---|---|
| **优选IP** | 测速、筛 IP | 需要给客户端填节点地址时 |
| **ProxyIP** | 检测反代中继 | 用 edgetunnel 且节点连不上时 |
| **优化工具** | Hosts、订阅优化 | 想让浏览器直连也变快、或订阅老更新失败时 |

> [!TIP]
> **测速前请关闭 VPN / 代理软件**。
>
> 开着代理测出来的延迟是「你到代理出口」的，不是本地网络到 Cloudflare 的真实情况。程序在开始测速时会检测系统代理并提醒你。

---

## 4. 第一次测速（优选IP）

1. 左侧点「**优选IP**」
2. 顶部点场景预设「**新手推荐**」（会自动勾好来源和参数）
3. 点「**开始测速**」

程序会依次经历四个阶段，进度条上都能看到：

```text
加载 IP 来源 → [域名探测] → 延迟测速 → 下载测速
```

「新手推荐」不测下载，通常 **1~2 分钟**出结果。

### 看懂结果

```text
IP 地址        端口   平均延迟   丢包率   下载速度   地区   评分
104.16.0.1     443    62 ms      0%       40.7MB/s   HKG    96.2  推荐
```

- **评分** = 速度 50% + 延迟 35% + 丢包 15%
- 前 3 名标「推荐」并高亮
- 表格上方会有一句话结论，如「共筛选出 12 个可用 IP，最优 104.16.0.1:443」

### 拿到结果之后

| 要去哪 | 点什么 |
|---|---|
| 客户端订阅 / 节点地址 | 「复制」→ 选 `IP:端口` 格式 |
| 表格分析 | 「导出 CSV」 |
| 下次再测 | 「导出 TXT」，可以作为 IP 来源文件 |
| 让浏览器直连也变快 | 去「优化工具」写 Hosts |

## 5. 第一次检测 ProxyIP（用 edgetunnel 才需要）

> 如果你不用 edgetunnel，或者节点一切正常，**可以跳过这一步**。

1. 左侧点「**ProxyIP**」
2. 点「**cmliussss 地区域名**」（最快，18 条，几秒出结果）
3. 检测完成后，只看标「**可用**」的行
4. 点「**复制为 PROXYIP**」
5. 粘进 edgetunnel 的 `PROXYIP` 设置，保存

得到的是一行逗号分隔的地址，例如：

```text
3.0.50.69:443,ProxyIP.CA.CMLiussss.net:443
```

> [!WARNING]
> 标「**直连CF**」的**不能填**。它的出口就是你自己，中间没中转，填进去只会让 Worker 绕一圈回到同一个 Cloudflare。
>
> 标「**待验证**」的本机测不了，但 Worker 里可能能用，可以配进去实测。

详细说明见 [ProxyIP 详解](ProxyIP)。

---

## 6. 第一次用 Hosts 加速

> 适合场景：你在浏览器里直接访问自己的域名（比如 `fast3.example.com`），希望也走最快的 IP。

1. 先在「优选IP」测出结果
2. **关闭程序**，右键 `cfstx.exe` →「**以管理员身份运行**」
3. 左侧点「**优化工具**」
4. 从列表里选一个 **443 端口**的结果，或在输入框手填 IP
5. 填域名（多个用换行分隔）
6. 点「**应用到 Hosts**」

程序会：

- 自动备份原 hosts 到 `%APPDATA%\CFSTX\hosts-backup\`
- 只修改 `# === CFSTX BEGIN ===` 到 `# === CFSTX END ===` 之间的内容
- 写完后自动执行 `ipconfig /flushdns`

然后 `Ctrl + F5` 刷新浏览器就能看到效果。

> [!WARNING]
> Hosts 只做「域名 → IP」映射，**不支持端口**，浏览器访问 https 固定走 443。
> 所以只能选 443 端口的结果；填 `1.2.3.4:10001` 会被拒绝。
>
> **不支持通配符** `*.example.com`，需要把子域名逐个写全。
